#Scarica Caesar per Windows, macOS e Linux

Caesar si può usare gratis (modalità Guest; Pro è un abbonamento opzionale) ed è Fair Source (licenza FSL: non è open source e venderlo è vietato). Gli installer sono pubblicati su GitHub Releases e nell'Ubuntu App Center (Snap Store); sarà disponibile presto anche su Microsoft Store.

Caesar è Fair Source. Puoi leggere e usare il codice liberamente. Ho scelto questo modello per mantenere il progetto sostenibile nel lungo periodo, proteggendo l'attività e garantendo al 100% la trasparenza su come gestisco i tuoi dati locali e i tuoi token. Licenza

Requisiti

  • Windows: 64 bit. Caesar usa il WebView2 di sistema; se manca, se ne occupa l'installer. In arrivo su Microsoft Store.
  • macOS: Intel o Apple Silicon (il .dmg è universale).
  • Linux: x86_64. Su Ubuntu (e sulle distro con snapd) il pacchetto Snap Store (sudo snap install caesar) include tutto il necessario. Con .deb o AppImage serve WebKitGTK 4.1 (per esempio Ubuntu 22.04 o successivo).
  • Non serve nessun account: la modalità guest funziona senza.

Passaggi di installazione

Windows

  1. Scarica il .exe (o il .msi).
  2. Eseguilo e segui la procedura guidata (se compare la schermata SmartScreen, clicca su Ulteriori informazioni → Esegui comunque).
  3. Apri Caesar dal menu Start.

In arrivo su Microsoft Store: nel frattempo la schermata SmartScreen compare ancora con l'installer diretto, ma quando sarà pubblicato su Microsoft Store potrai scaricarlo da lì e quell'avviso non comparirà più.

macOS

  1. Scarica il .dmg e aprilo.
  2. Trascina Caesar nella cartella Applicazioni.
  3. Aprilo da Applicazioni o da Launchpad.

Ubuntu e Linux

Su Ubuntu puoi installarlo dall'Ubuntu App Center (Snap Store) o eseguendo nel terminale:

sudo snap install caesar

Se preferisci il pacchetto .deb (Ubuntu/Debian):

sudo apt install ./Caesar_x.y.z_amd64.deb

oppure, con l'AppImage su qualsiasi distro:

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

Ubuntu e altre distro

Su Ubuntu l'opzione più comoda è installare dall'Ubuntu App Center (Snap Store) o con sudo snap install caesar: si installa in un solo passaggio e si aggiorna automaticamente. Con il .deb, apt può mostrare una nota innocua se il file si trova nella tua cartella home; l'AppImage richiede il permesso di esecuzione.

Terminale — ubuntu
user@ubuntu:~$ sudo snap install caesar

user@ubuntu:~$ # Or with the .deb package:
user@ubuntu:~$ sudo apt install ./Caesar_x.y.z_amd64.deb

Per l'AppImage: chmod +x Caesar_*.AppImage e aprila. Se la tua distro non la esegue, installa libfuse2.

Perché compare? È normale

Caesar è un progetto nuovo con codice sorgente disponibile: è completamente nuovo e non ha ancora uno storico di download.

SmartScreen e sistemi simili valutano la reputazione di un file e se ha un certificato di firma del codice a pagamento. Un programma appena pubblicato non ha né l'una né l'altro, e l'avviso compare per qualsiasi software nuovo.

L'avviso non significa che sia pericoloso: significa che il sistema non lo conosce ancora. Puoi verificarlo tu stesso: tutto il codice è pubblico e puoi controllare il file con il suo hash SHA-256 (qui sotto).

Come verificare l'integrità

In ogni pagina di Release, GitHub mostra un digest SHA-256 accanto a ogni file in Assets. Calcola l'hash del file che hai scaricato e controlla che coincida:

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

Se non coincide, non installarlo e scaricalo di nuovo. Questo controllo rileva download corrotti o alterati, ma non sostituisce la firma del codice (vedi sotto). Anche gli aggiornamenti automatici sono firmati con minisign e l'app verifica la firma prima di installarli.

Aggiornamenti automatici

  • Per impostazione predefinita, all'avvio l'app controlla github.com/cesargarridor/caesar/releases in cerca di una nuova versione; se c'è, la scarica, la installa e si riavvia da sola. Le tue schede e le tue bozze vengono mantenute.
  • Ogni pacchetto di aggiornamento è firmato con minisign e l'app controlla la firma prima di installarlo.
  • Per disattivarli: Impostazioni → Aggiornamenti. Da lì puoi anche cliccare su Verifica aggiornamenti quando vuoi.
  • Su Linux, se installi Caesar dallo Snap Store (sudo snap install caesar o l'Ubuntu App Center), Snap lo aggiorna automaticamente in background; con l'AppImage si aggiorna dentro l'app, mentre il .deb va reinstallato a mano.
  • Quando controlla gli aggiornamenti, GitHub riceve il tuo indirizzo IP e una richiesta standard; consulta l'informativa sulla privacy per i dettagli.

Privacy

Caesar non include telemetria né analytics. In modalità Guest/locale i tuoi dati non lasciano il dispositivo; con Sync vengono caricati solo blocchi cifrati. Pro è un abbonamento che si rinnova automaticamente: prezzo e periodo di fatturazione sono mostrati prima di pagare, puoi disdire quando vuoi e ottenere un rimborso entro 14 giorni (rimborsi, termini). Leggi l'informativa sulla privacy e la pagina sulla sicurezza.
