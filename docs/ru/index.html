FAQ

Безопасность, предупреждения и мелкий шрифт

What is the SmartScreen warning on Windows?
При использовании прямого установщика для Windows по-прежнему появляется экран Microsoft Defender SmartScreen («Windows защитила ваш компьютер»), потому что у установщика пока нет платной подписи кода. Так бывает с любой новой программой без истории загрузок: система просто ещё не знает её, а вовсе не считает опасной. Нажмите Подробнее, затем Выполнить в любом случае. Caesar скоро появится в Microsoft Store: после публикации вы сможете скачать его прямо из магазина, и экран SmartScreen больше не появится.
Why isn't it signed on Linux?
В Linux нет системы репутации, как SmartScreen, поэтому предупреждений безопасности вы не увидите. В Ubuntu можно установить Caesar прямо из App Center (Snap Store) или командой sudo snap install caesar (он обновляется автоматически). При установке .deb утилита apt может показать безвредное уведомление, если файл лежит в вашей домашней папке. Для AppImage сделайте файл исполняемым (chmod +x Caesar_*.AppImage); если ваш дистрибутив не открывает его, установите libfuse2.
And on macOS?
Caesar для macOS подписан и нотаризован Apple, поэтому предупреждения о «неопознанном разработчике» нет. Вы увидите лишь стандартный запрос при первом запуске: нажмите Открыть.
How does Caesar Sync's E2E encryption work?
Ваши данные шифруются на вашем компьютере алгоритмом AES-256-GCM перед отправкой. Ключ данных хранится только в связке ключей ОС и никогда не покидает ваш компьютер, поэтому сервер видит только зашифрованные блоки. Важно: если вы потеряете все свои устройства и ключ восстановления, зашифрованные данные восстановить будет невозможно — такова цена того, что никто другой не может их прочитать.
Does it collect telemetry or analytics?
Нет. В Caesar нет телеметрии и аналитики, а этот сайт не использует трекинговые cookie. В гостевом режиме ваши данные никогда не покидают ваш компьютер. Если вы создаёте аккаунт или активируете Pro, обрабатываются данные аккаунта и оплаты, описанные в политике конфиденциальности.
Do I need an account?
Нет. Гостевой режим работает без аккаунта, хранит данные только на вашем устройстве и допускает 2 локальных рабочих пространства. Аккаунт (7-дневный локальный пробный период, затем Pro) и Caesar Sync — опциональны.
How do I cancel Pro, and what about refunds?
Отмените подписку в один клик в приложении: Настройки → Аккаунт и подписка → Управление подпиской. Pro сохраняется до конца оплаченного периода, а на любой платёж действует 14-дневный срок возврата. Платежи обрабатывает Polar как Merchant of Record.
Is it open source? What is Fair Source (FSL)?
Caesar распространяется по лицензии Functional Source License 1.1 с будущей лицензией MIT (FSL-1.1-MIT). Код открыт: вы можете читать его, бесплатно использовать, изменять и делиться своими изменениями. Это не open source (лицензия не соответствует определению OSI): продавать его или использовать для предложения конкурирующего коммерческого продукта или сервиса запрещено. Каждая версия становится MIT через два года после выпуска.
What is the Collection Runner with CSV?
Запускает целую папку или коллекцию, отправляя каждый запрос со строкой CSV в качестве переменных. Удобно для одновременной проверки множества случаев. Это функция Pro.
Which systems does it run on?
Windows (.exe и .msi; скоро в Microsoft Store), macOS (Intel и Apple Silicon, универсальный .dmg) и Linux (Ubuntu Snap Store через sudo snap install caesar, .deb и AppImage). Обновляется самостоятельно через подписанные пакеты или через магазин.
