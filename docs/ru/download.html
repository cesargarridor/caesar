Требования

  • Windows: 64-разрядная. Caesar использует системный WebView2; установщик сам позаботится о нём, если он отсутствует. Скоро в Microsoft Store.
  • macOS: Intel или Apple Silicon (.dmg универсальный).
  • Linux: x86_64. В Ubuntu (и дистрибутивах с snapd) пакет из Snap Store (sudo snap install caesar) содержит всё необходимое. Для .deb или AppImage требуется WebKitGTK 4.1 (например, Ubuntu 22.04 или новее).
  • Аккаунт не нужен: гостевой режим работает без него.

Шаги установки

Windows

  1. Скачайте .exe (или .msi).
  2. Запустите его и следуйте мастеру установки (если появится экран SmartScreen, нажмите Подробнее → Выполнить в любом случае).
  3. Откройте Caesar из меню «Пуск».

Скоро в Microsoft Store: пока что с прямым установщиком экран SmartScreen по-прежнему появляется, но после публикации в Microsoft Store вы сможете скачать приложение оттуда, и это предупреждение больше не появится.

macOS

  1. Скачайте .dmg и откройте его.
  2. Перетащите Caesar в папку «Программы».
  3. Откройте его из «Программ» или через Launchpad.

Ubuntu и Linux

В Ubuntu можно установить его из Ubuntu App Center (Snap Store) или выполнив в терминале:

sudo snap install caesar

Если вы предпочитаете пакет .deb (Ubuntu/Debian):

sudo apt install ./Caesar_x.y.z_amd64.deb

или, с AppImage в любом дистрибутиве:

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

Ubuntu и другие дистрибутивы

В Ubuntu проще всего установить из Ubuntu App Center (Snap Store) или командой sudo snap install caesar: установка в один шаг и автоматические обновления. С .deb утилита apt может вывести безвредное уведомление, если файл лежит в вашей домашней папке; AppImage требует права на выполнение.

Терминал — ubuntu

Для AppImage: chmod +x Caesar_*.AppImage и откройте его. Если ваш дистрибутив не запускает его, установите libfuse2.

Почему это появляется? Это нормально

Caesar — новый проект с доступным исходным кодом: он совсем новый и пока не имеет истории загрузок.

SmartScreen и подобные системы смотрят на репутацию файла и на наличие платного сертификата подписи кода. У только что опубликованной программы нет ни того, ни другого, и предупреждение появляется для любого нового ПО.

Предупреждение не означает, что программа опасна: оно означает, что система её ещё не знает. Вы можете проверить всё сами: весь код открыт, а файл можно проверить по хешу SHA-256 (ниже).

Как проверить целостность

На странице каждого релиза GitHub показывает дайджест SHA-256 рядом с каждым файлом в разделе Assets. Вычислите хеш скачанного файла и убедитесь, что он совпадает:

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

Если он не совпадает, не устанавливайте файл и скачайте его заново. Эта проверка выявляет повреждённые или изменённые загрузки, но не заменяет подпись кода (см. ниже). Автоматические обновления также подписаны с помощью minisign, и приложение проверяет подпись перед установкой.

Автоматические обновления

  • По умолчанию при запуске приложение проверяет github.com/cesargarridor/caesar/releases на наличие новой версии; если она есть, оно скачивает её, устанавливает и перезапускается само. Ваши вкладки и черновики сохраняются.
  • Каждый пакет обновления подписан с помощью minisign, и приложение проверяет подпись перед установкой.
  • Чтобы отключить их: Настройки → Обновления. Оттуда же в любой момент можно нажать Проверить обновления.
  • В Linux, если вы устанавливаете Caesar из Snap Store (sudo snap install caesar или Ubuntu App Center), Snap обновляет его автоматически в фоне; с AppImage обновление происходит внутри приложения, а .deb нужно переустанавливать вручную.
  • При проверке обновлений GitHub получает ваш IP-адрес и стандартный запрос; подробности см. в политике конфиденциальности.

Конфиденциальность

В Caesar нет телеметрии и аналитики. В гостевом/локальном режиме ваши данные не покидают устройство; при синхронизации загружаются только зашифрованные блоки. Pro — подписка с автоматическим продлением: цена и период оплаты показываются до оплаты, отменить можно в любой момент, а возврат возможен в течение 14 дней (возвраты, условия). Прочитайте политику конфиденциальности и страницу о безопасности.
