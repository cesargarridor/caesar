Requirements

  • Windows: 64-bit. Caesar uses the system WebView2; the installer takes care of it if it is missing. Coming soon to the Microsoft Store.
  • macOS: Intel or Apple Silicon (the .dmg is universal).
  • Linux: x86_64. On Ubuntu (and distros with snapd) the Snap Store package (sudo snap install caesar) bundles everything needed. With .deb or AppImage, WebKitGTK 4.1 is required (for example Ubuntu 22.04 or later).
  • No account needed: guest mode works without one.

Installation steps

Windows

  1. Download the .exe (or the .msi).
  2. Run it and follow the wizard (if the SmartScreen screen appears, click More info → Run anyway).
  3. Open Caesar from the Start menu.

Coming soon to the Microsoft Store: in the meantime the SmartScreen screen still appears with the direct installer, but once it is published on the Microsoft Store you will be able to download it from there and that warning will no longer appear.

macOS

  1. Download the .dmg and open it.
  2. Drag Caesar to the Applications folder.
  3. Open it from Applications or Launchpad.

Ubuntu and Linux

On Ubuntu you can install it from the Ubuntu App Center (Snap Store) or by running in your terminal:

sudo snap install caesar

If you prefer the .deb package (Ubuntu/Debian):

sudo apt install ./Caesar_x.y.z_amd64.deb

or, with the AppImage on any distro:

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

Ubuntu and other distros

On Ubuntu the easiest option is installing from the Ubuntu App Center (Snap Store) or with sudo snap install caesar: it installs in one step and updates automatically. With the .deb, apt may print a harmless note if the file is in your home folder; the AppImage needs execute permission.

Terminal — ubuntu
user@ubuntu:~$ sudo snap install caesar
caesar 0.18.25 from Cesar Garrido installed
user@ubuntu:~$ # Or with the .deb package:
user@ubuntu:~$ sudo apt install ./Caesar_x.y.z_amd64.deb
Reading package lists... Done
...
N: Download is performed unsandboxed as root as file '/home/user/Caesar_x.y.z_amd64.deb' couldn't be accessed by user '_apt'. - pkgAcquire::Run (13: Permission denied)

For the AppImage: chmod +x Caesar_*.AppImage and open it. If your distro will not run it, install libfuse2.

Why does this appear? It is normal

Caesar is a new project with source available: it is completely new and has no download history yet.

SmartScreen and similar systems look at a file's reputation and whether it has a paid code-signing certificate. A freshly published program has neither, and the warning shows up for any new software.

The warning does not mean it is dangerous: it means the system does not know it yet. You can check it yourself: all the code is public and you can verify the file with its SHA-256 hash (below).

How to verify integrity

On each Release page, GitHub shows a SHA-256 digest next to every file under Assets. Compute the hash of the file you downloaded and check that it matches:

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

If it does not match, do not install it and download it again. This check detects corrupted or altered downloads but does not replace code signing (see below). Automatic updates are also signed with minisign and the app verifies the signature before installing them.

Automatic updates

  • By default, on startup the app checks github.com/cesargarridor/caesar/releases for a new version; if there is one, it downloads it, installs it and restarts by itself. Your tabs and drafts are kept.
  • Each update package is signed with minisign and the app checks the signature before installing it.
  • To turn them off: Settings → Updates. From there you can also click Check for updates whenever you want.
  • On Linux, if you install Caesar from the Snap Store (sudo snap install caesar or the Ubuntu App Center), Snap updates it automatically in the background; with the AppImage it updates inside the app, and the .deb must be reinstalled by hand.
  • When checking for updates, GitHub receives your IP address and a standard request; see the privacy policy for details.

Privacy

Caesar includes no telemetry or analytics. In Guest/local mode your data does not leave your device; with Sync only encrypted blocks are uploaded. Pro is a subscription that renews automatically: price and billing period are shown before you pay, you can cancel any time and get a 14-day refund (refunds, terms).
