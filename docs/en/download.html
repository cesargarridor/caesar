Requirements

  • Windows: 64-bit. Caesar uses the system WebView2; the installer takes care of it if it is missing.
  • macOS: Intel or Apple Silicon (the .dmg is universal).
  • Linux: x86_64 with WebKitGTK 4.1 (for example Ubuntu 22.04 or later). The .deb declares its dependencies; the AppImage bundles most of them but needs a recent distro. Packages are built on Ubuntu 22.04.
  • No account needed: guest mode works without one.

Installation steps

Windows

  1. Download the .exe (or the .msi).
  2. Run it and follow the wizard.
  3. Open Caesar from the Start menu.

macOS

  1. Download the .dmg and open it.
  2. Drag Caesar to the Applications folder.
  3. Open it from Applications or Launchpad.

Linux

sudo apt install ./Caesar_x.y.z_amd64.deb

or, with the AppImage:

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

First launch: system warnings

  • Windows (SmartScreen): the Windows installer is not code-signed yet, so Windows may show "Windows protected your PC" or "unknown publisher". If you downloaded the file from the official Releases page, click More info and then Run anyway.
  • macOS (Gatekeeper): the app is signed and notarized with Apple in the release workflow, so it should not normally warn. If a warning still appears, right-click Caesar → Open → Open; if that option is missing, go to System Settings → Privacy & Security and click Open Anyway.
  • Linux: no warning; just make the AppImage executable.

How to verify integrity

On each Release page, GitHub shows a SHA-256 digest next to every file under Assets. Compute the hash of the file you downloaded and check that it matches:

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

If it does not match, do not install it and download it again. This check detects corrupted or altered downloads but does not replace code signing (see below). Automatic updates are also signed with minisign and the app verifies the signature before installing them.

Automatic updates

  • By default, on startup the app checks github.com/cesargarridor/caesar/releases for a new version; if there is one, it downloads it, installs it and restarts by itself. Your tabs and drafts are kept.
  • Each update package is signed with minisign and the app checks the signature before installing it.
  • To turn them off: Settings → Updates. From there you can also click Check for updates whenever you want.
  • On Linux, auto-update only works with the AppImage; the .deb must be reinstalled by hand.
  • When checking for updates, GitHub receives your IP address and a standard request; see the privacy policy for details.

Privacy

Caesar includes no telemetry or analytics. Read the privacy policy and the security page.
