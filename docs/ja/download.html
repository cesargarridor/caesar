システム別ダウンロード

お使いのシステムを選んでください。最新バージョンのダウンロードがすぐに始まります。

Ubuntuの場合：Ubuntu App Center（Snap Store）から直接、またはターミナルでsudo snap install caesarを実行してインストールできます · Ubuntu/Debian用に.debをお探しですか？

Windowsの場合（Microsoft Storeに近日登場）：直接インストーラー（.exeと.msi）では、Windows SmartScreenの青い画面が引き続き表示されます（詳細情報 → 実行をクリックしてください）。アプリがMicrosoft Storeで公開されれば、そこから直接ダウンロードでき、SmartScreenの画面は表示されなくなります。

動作要件

  • Windows：64ビット。CaesarはシステムのWebView2を使用します。未インストールの場合は、インストーラーが対応します。Microsoft Storeに近日登場。
  • macOS：IntelまたはApple Silicon（.dmgはユニバーサルです）。
  • Linux：x86_64。Ubuntu（およびsnapdが使えるディストリビューション）では、Snap Storeパッケージ（sudo snap install caesar）に必要なものがすべて含まれています。.debまたはAppImageの場合はWebKitGTK 4.1が必要です（例：Ubuntu 22.04以降）。
  • アカウントは不要です。ゲストモードはアカウントなしで動作します。

インストール手順

Windows

  1. .exe（または.msi）をダウンロードします。
  2. 実行してウィザードの指示に従います（SmartScreenの画面が表示された場合は、詳細情報 → 実行をクリックしてください）。
  3. スタートメニューからCaesarを開きます。

Microsoft Storeに近日登場：それまでは、直接インストーラーでは引き続きSmartScreenの画面が表示されますが、Microsoft Storeで公開されれば、そこからダウンロードでき、この警告は表示されなくなります。

macOS

  1. .dmgをダウンロードして開きます。
  2. CaesarをApplicationsフォルダにドラッグします。
  3. ApplicationsまたはLaunchpadから開きます。

UbuntuとLinux

Ubuntuでは、Ubuntu App Center（Snap Store）からインストールするか、ターミナルで次のコマンドを実行してください。

sudo snap install caesar

.debパッケージをお好みの場合（Ubuntu/Debian）：

sudo apt install ./Caesar_x.y.z_amd64.deb

または、任意のディストリビューションでAppImageを使用する場合：

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

ダウンロード後：表示される可能性のある警告

警告はお使いのシステムによって異なります。システムを選ぶと、表示される内容と対処方法を確認できます。

macOS

macOS版CaesarはAppleによる署名と公証を受けているため、「未確認の開発元」という警告は表示されません。App Store以外からダウンロードしたアプリを初めて開くときに表示される通常のmacOSの確認画面のみです。信頼してよいか確認してください。

Ubuntuおよびその他のディストリビューション

Ubuntuでは、Ubuntu App Center（Snap Store）またはsudo snap install caesarからインストールするのが最も簡単です。1ステップでインストールでき、自動更新されます。.debの場合、ファイルがホームフォルダにあるとaptが無害な通知を表示することがあります。AppImageには実行権限が必要です。

ターミナル — ubuntu
user@ubuntu:~$ sudo snap install caesar
caesar 0.18.25 from Cesar Garrido installed
user@ubuntu:~$ # Or with the .deb package:
user@ubuntu:~$ sudo apt install ./Caesar_x.y.z_amd64.deb
Reading package lists... Done
...
N: Download is performed unsandboxed as root as file '/home/user/Caesar_x.y.z_amd64.deb' couldn't be accessed by user '_apt'. - pkgAcquire::Run (13: Permission denied)

AppImageの場合：chmod +x Caesar_*.AppImageを実行してから開いてください。お使いのディストリビューションで実行できない場合は、libfuse2をインストールしてください。

なぜ表示されるのか？ これは正常です

Caesarはソースが公開されている新しいプロジェクトであり、完全に新規で、まだダウンロード実績がありません。

SmartScreenなどのシステムは、ファイルの評価（レピュテーション）と、有料のコード署名証明書の有無を確認します。公開されたばかりのプログラムにはどちらもないため、新しいソフトウェアではすべてこの警告が表示されます。

この警告は危険であることを意味するものではありません。システムがまだ認識していないという意味です。ご自身で確認することもできます。コードはすべて公開されており、SHA-256ハッシュ（下記）でファイルを検証できます。

整合性の確認方法

各リリースページでは、GitHubがAssetsの各ファイルの横にSHA-256ダイジェストを表示しています。ダウンロードしたファイルのハッシュを計算し、一致していることを確認してください。

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

一致しない場合はインストールせず、もう一度ダウンロードしてください。この確認は、破損または改ざんされたダウンロードを検出するものであり、コード署名の代わりにはなりません（下記参照）。自動更新もminisignで署名されており、アプリはインストール前に署名を検証します。

自動更新

  • 既定では、アプリは起動時にgithub.com/cesargarridor/caesar/releasesで新バージョンを確認し、ある場合はダウンロード、インストールして自動的に再起動します。タブと下書きは保持されます。
  • 各更新パッケージはminisignで署名されており、アプリはインストール前に署名を確認します。
  • 無効にするには：設定 → 更新。そこから更新を確認をクリックして、いつでも手動で確認することもできます。
  • LinuxでSnap Store（sudo snap install caesarまたはUbuntu App Center）からCaesarをインストールした場合は、Snapがバックグラウンドで自動更新します。AppImageはアプリ内で更新され、.debは手動で再インストールする必要があります。
  • 更新を確認する際、GitHubはお使いのIPアドレスと標準的なリクエストを受信します。詳細はプライバシーポリシーをご覧ください。
