FAQ

セキュリティ、警告、注意事項

What is the SmartScreen warning on Windows?
Windowsの直接インストーラーでは、有料のコード署名がまだ付与されていないため、Microsoft Defender SmartScreenの画面（「Windows によってPCが保護されました」）が引き続き表示されます。ダウンロード実績のない新しいプログラムではよくあることで、システムがまだ認識していないだけであり、危険という意味ではありません。詳細情報をクリックし、続いて実行をクリックしてください。CaesarはまもなくMicrosoft Storeで提供開始予定です。公開後はストアから直接ダウンロードでき、SmartScreenの画面は表示されなくなります。
Why isn't it signed on Linux?
LinuxにはSmartScreenのような評価システムがないため、セキュリティ警告は表示されません。Ubuntuでは、App Center（Snap Store）から、またはsudo snap install caesarで直接インストールできます（自動更新されます）。.debの場合、ファイルがホームフォルダにあるとaptが無害な通知を表示することがあります。AppImageの場合は、実行権限を付与してください（chmod +x Caesar_*.AppImage）。お使いのディストリビューションで開けない場合は、libfuse2をインストールしてください。
And on macOS?
macOS版CaesarはAppleによる署名と公証を受けているため、「未確認の開発元」という警告は表示されません。初回起動時の通常の確認画面で開くをクリックするだけです。
How does Caesar Sync's E2E encryption work?
データはアップロード前に、お使いのマシン上でAES-256-GCMにより暗号化されます。データキーはOSのキーリングにのみ保存され、マシンの外には出ません。そのためサーバーが目にするのは暗号化されたブロックだけです。ご注意：すべてのデバイスとリカバリーキーを紛失した場合、暗号化されたデータは復元できません。これは、他の誰にも読み取れないことの代償です。
Does it collect telemetry or analytics?
いいえ。Caesarにはテレメトリーも分析機能もなく、このサイトでもトラッキングCookieは使用していません。ゲストモードでは、データがお使いのマシンの外に出ることはありません。アカウントを作成するかProを有効化した場合は、プライバシーポリシーに記載のアカウント情報と請求情報が処理されます。
Do I need an account?
いいえ。ゲストモードはアカウントなしで動作し、データはお使いのデバイスにのみ保存され、ローカルワークスペースを2つまで利用できます。アカウント（7日間のローカルトライアル、その後Pro）とCaesar Syncは任意です。
How do I cancel Pro, and what about refunds?
アプリからワンクリックで解約できます：設定 → アカウントとサブスクリプション → サブスクリプションを管理。お支払い済みの期間が終わるまでProをご利用いただけます。また、どの請求も14日間の返金対象です。決済はMerchant of RecordであるPolarが処理します。
Is it open source? What is Fair Source (FSL)?
CaesarはFunctional Source License 1.1（将来MITライセンスに移行：FSL-1.1-MIT）を採用しています。コードは公開されており、読んだり、無料で使用したり、変更したり、変更内容を共有したりできます。オープンソースではありません（OSIの定義を満たしていません）：販売することや、競合する商用製品・サービスの提供に使用することは禁止されています。各バージョンはリリースから2年後にMITライセンスになります。
What is the Collection Runner with CSV?
フォルダまたはコレクション全体を実行し、CSVの各行を変数として各リクエストを送信します。多数のケースを一度にテストするのに便利です。Pro機能です。
Which systems does it run on?
Windows（.exeと.msi。Microsoft Storeに近日登場）、macOS（IntelとApple Silicon対応のユニバーサル.dmg）、Linux（sudo snap install caesarによるUbuntu Snap Store、.deb、AppImage）に対応しています。署名済みパッケージまたはストア経由で自動更新されます。
