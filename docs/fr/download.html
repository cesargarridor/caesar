#Télécharger Caesar pour Windows, macOS et Linux

Caesar est utilisable gratuitement (mode Invité ; Pro est un abonnement facultatif) et Fair Source (licence FSL : pas open source, et sa vente est interdite). Les installeurs sont publiés sur GitHub Releases et dans l’Ubuntu App Center (Snap Store) ; il sera aussi bientôt disponible sur le Microsoft Store.

Caesar est Fair Source. Tu peux lire et utiliser le code librement. J’ai choisi ce modèle pour garder le projet durable à long terme, en protégeant l’activité tout en restant 100 % transparent sur la façon dont je traite tes données locales et tes tokens. Licence

Prérequis

  • Windows : 64 bits. Caesar utilise le WebView2 du système ; l’installeur s’en charge s’il manque. Bientôt sur le Microsoft Store.
  • macOS : Intel ou Apple Silicon (le .dmg est universel).
  • Linux : x86_64. Sur Ubuntu (et les distributions avec snapd), le paquet Snap Store (sudo snap install caesar) embarque tout le nécessaire. Avec le .deb ou l’AppImage, WebKitGTK 4.1 est requis (par exemple Ubuntu 22.04 ou version ultérieure).
  • Aucun compte nécessaire : le mode invité fonctionne sans.

Étapes d’installation

Windows

  1. Télécharge le .exe (ou le .msi).
  2. Lance-le et suis l’assistant (si l’écran SmartScreen apparaît, clique sur Informations complémentaires → Exécuter quand même).
  3. Ouvre Caesar depuis le menu Démarrer.

Bientôt sur le Microsoft Store : en attendant, l’écran SmartScreen s’affiche encore avec l’installeur direct, mais une fois l’app publiée sur le Microsoft Store, tu pourras la télécharger depuis là et cet avertissement n’apparaîtra plus.

macOS

  1. Télécharge le .dmg et ouvre-le.
  2. Glisse Caesar dans le dossier Applications.
  3. Ouvre-le depuis Applications ou le Launchpad.

Ubuntu et Linux

Sur Ubuntu, tu peux l’installer depuis l’Ubuntu App Center (Snap Store) ou en exécutant dans ton terminal :

sudo snap install caesar

Si tu préfères le paquet .deb (Ubuntu/Debian) :

sudo apt install ./Caesar_x.y.z_amd64.deb

ou, avec l’AppImage sur n’importe quelle distribution :

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

Ubuntu et autres distributions

Sur Ubuntu, le plus simple est d’installer depuis l’Ubuntu App Center (Snap Store) ou avec sudo snap install caesar : l’installation se fait en une étape et se met à jour automatiquement. Avec le .deb, apt peut afficher une note sans gravité si le fichier se trouve dans ton dossier personnel ; l’AppImage a besoin du droit d’exécution.

Terminal — ubuntu
user@ubuntu:~$ sudo snap install caesar
caesar 0.18.25 from Cesar Garrido installed
user@ubuntu:~$ # Or with the .deb package:
user@ubuntu:~$ sudo apt install ./Caesar_x.y.z_amd64.deb
Reading package lists... Done
...
N: Download is performed unsandboxed as root as file '/home/user/Caesar_x.y.z_amd64.deb' couldn't be accessed by user '_apt'. - pkgAcquire::Run (13: Permission denied)

Pour l’AppImage : chmod +x Caesar_*.AppImage puis ouvre-la. Si ta distribution refuse de l’exécuter, installe libfuse2.

Pourquoi cet avertissement ? C’est normal

Caesar est un nouveau projet à code source disponible : il est tout neuf et n’a pas encore d’historique de téléchargements.

SmartScreen et les systèmes similaires examinent la réputation d’un fichier et s’il possède un certificat de signature de code payant. Un programme fraîchement publié n’a ni l’un ni l’autre, et l’avertissement s’affiche pour tout nouveau logiciel.

L’avertissement ne signifie pas que c’est dangereux : il signifie que le système ne le connaît pas encore. Tu peux le vérifier toi-même : tout le code est public et tu peux contrôler le fichier avec son empreinte SHA-256 (ci-dessous).

Comment vérifier l’intégrité

Sur chaque page de Release, GitHub affiche une empreinte SHA-256 à côté de chaque fichier sous Assets. Calcule l’empreinte du fichier téléchargé et vérifie qu’elle correspond :

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

Si elle ne correspond pas, ne l’installe pas et télécharge-le à nouveau. Cette vérification détecte les téléchargements corrompus ou altérés mais ne remplace pas la signature de code (voir plus bas). Les mises à jour automatiques sont aussi signées avec minisign et l’app vérifie la signature avant de les installer.

Mises à jour automatiques

  • Par défaut, au démarrage l’app consulte github.com/cesargarridor/caesar/releases pour détecter une nouvelle version ; s’il y en a une, elle la télécharge, l’installe et redémarre toute seule. Tes onglets et brouillons sont conservés.
  • Chaque paquet de mise à jour est signé avec minisign et l’app vérifie la signature avant de l’installer.
  • Pour les désactiver : Paramètres → Mises à jour. Tu peux aussi y cliquer sur Rechercher des mises à jour quand tu veux.
  • Sur Linux, si tu installes Caesar depuis le Snap Store (sudo snap install caesar ou l’Ubuntu App Center), Snap le met à jour automatiquement en arrière-plan ; avec l’AppImage, la mise à jour se fait dans l’app, et le .deb doit être réinstallé à la main.
  • Lors de la recherche de mises à jour, GitHub reçoit ton adresse IP et une requête standard ; consulte la politique de confidentialité pour plus de détails.

Confidentialité

Caesar n’inclut ni télémétrie ni analytique. En mode Invité/local, tes données ne quittent pas ton appareil ; avec Sync, seuls des blocs chiffrés sont envoyés. Pro est un abonnement qui se renouvelle automatiquement : le prix et la période de facturation sont affichés avant de payer, tu peux résilier à tout moment et obtenir un remboursement sous 14 jours (remboursements, conditions). Lis la politique de confidentialité et la page de sécurité.
