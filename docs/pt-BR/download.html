#Baixar o Caesar para Windows, macOS e Linux

O Caesar pode ser usado gratuitamente (modo Convidado; o Pro é uma assinatura opcional) e é Fair Source (licença FSL: não é código aberto, e é proibido vendê-lo). Os instaladores são publicados no GitHub Releases e na Ubuntu App Center (Snap Store); em breve também estará disponível na Microsoft Store.

O Caesar é Fair Source. Você pode ler e usar o código livremente. Escolhi este modelo para manter o projeto sustentável a longo prazo, protegendo o negócio e, ao mesmo tempo, mantendo 100% de transparência sobre como trato seus dados locais e tokens. Licença

Requisitos

  • Windows: 64 bits. O Caesar usa o WebView2 do sistema; o instalador cuida disso se ele estiver ausente. Em breve na Microsoft Store.
  • macOS: Intel ou Apple Silicon (o .dmg é universal).
  • Linux: x86_64. No Ubuntu (e distros com snapd) o pacote da Snap Store (sudo snap install caesar) já traz tudo o que é necessário. Com .deb ou AppImage, é preciso o WebKitGTK 4.1 (por exemplo, Ubuntu 22.04 ou posterior).
  • Não precisa de conta: o modo convidado funciona sem uma.

Passos de instalação

Windows

  1. Baixe o .exe (ou o .msi).
  2. Execute-o e siga o assistente (se a tela do SmartScreen aparecer, clique em Mais informações → Executar assim mesmo).
  3. Abra o Caesar pelo menu Iniciar.

Em breve na Microsoft Store: por enquanto a tela do SmartScreen ainda aparece com o instalador direto, mas quando ele for publicado na Microsoft Store você poderá baixá-lo de lá e esse aviso não aparecerá mais.

macOS

  1. Baixe o .dmg e abra-o.
  2. Arraste o Caesar para a pasta Aplicativos.
  3. Abra-o pela pasta Aplicativos ou pelo Launchpad.

Ubuntu e Linux

No Ubuntu você pode instalá-lo pela Ubuntu App Center (Snap Store) ou executando no terminal:

sudo snap install caesar

Se preferir o pacote .deb (Ubuntu/Debian):

sudo apt install ./Caesar_x.y.z_amd64.deb

ou, com o AppImage em qualquer distro:

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

Ubuntu e outras distros

No Ubuntu a opção mais fácil é instalar pela Ubuntu App Center (Snap Store) ou com sudo snap install caesar: instala em um passo e se atualiza sozinho. Com o .deb, o apt pode exibir um aviso inofensivo se o arquivo estiver na sua pasta pessoal; o AppImage precisa de permissão de execução.

Terminal — ubuntu
user@ubuntu:~$ sudo snap install caesar
caesar 0.18.25 from Cesar Garrido installed
user@ubuntu:~$ # Or with the .deb package:
user@ubuntu:~$ sudo apt install ./Caesar_x.y.z_amd64.deb
Reading package lists... Done
...
N: Download is performed unsandboxed as root as file '/home/user/Caesar_x.y.z_amd64.deb' couldn't be accessed by user '_apt'. - pkgAcquire::Run (13: Permission denied)

Para o AppImage: chmod +x Caesar_*.AppImage e abra-o. Se a sua distro não o executar, instale o libfuse2.

Por que isso aparece? É normal

O Caesar é um projeto novo com código-fonte disponível: é totalmente novo e ainda não tem histórico de downloads.

O SmartScreen e sistemas semelhantes avaliam a reputação de um arquivo e se ele tem um certificado pago de assinatura de código. Um programa recém-publicado não tem nenhum dos dois, e o aviso aparece para qualquer software novo.

O aviso não significa que seja perigoso: significa que o sistema ainda não o conhece. Você mesmo pode conferir: todo o código é público e você pode verificar o arquivo com o hash SHA-256 (abaixo).

Como verificar a integridade

Na página de cada Release, o GitHub mostra um digest SHA-256 ao lado de cada arquivo em Assets. Calcule o hash do arquivo que você baixou e confira se ele coincide:

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

Se não coincidir, não o instale e baixe-o novamente. Essa verificação detecta downloads corrompidos ou adulterados, mas não substitui a assinatura de código (veja abaixo). As atualizações automáticas também são assinadas com minisign e o app verifica a assinatura antes de instalá-las.

Atualizações automáticas

  • Por padrão, ao iniciar, o app consulta github.com/cesargarridor/caesar/releases em busca de uma nova versão; se houver, ele a baixa, instala e reinicia sozinho. Suas abas e rascunhos são mantidos.
  • Cada pacote de atualização é assinado com minisign e o app confere a assinatura antes de instalá-lo.
  • Para desativá-las: Configurações → Atualizações. De lá você também pode clicar em Verificar atualizações quando quiser.
  • No Linux, se você instalar o Caesar pela Snap Store (sudo snap install caesar ou pela Ubuntu App Center), o Snap o atualiza automaticamente em segundo plano; com o AppImage ele se atualiza dentro do app, e o .deb precisa ser reinstalado manualmente.
  • Ao verificar atualizações, o GitHub recebe o seu endereço IP e uma requisição padrão; consulte a política de privacidade para mais detalhes.

Privacidade

O Caesar não inclui telemetria nem análises. No modo Convidado/local seus dados não saem do seu dispositivo; com o Sync, apenas blocos criptografados são enviados. O Pro é uma assinatura que renova automaticamente: o preço e o período de cobrança são exibidos antes de você pagar, você pode cancelar quando quiser e pedir reembolso em 14 dias (reembolsos, termos). Leia a política de privacidade e a página de segurança.
