Caesar 指南：逐项详解每个功能

Caesar 是一款追求速度的桌面 API 客户端：即开即用，所有内容都保存在你的机器上，无需账号即可上手。本指南逐项讲解每个功能，并附上真实效果的 GIF，从你的第一个请求，到测试、GraphQL、WebSocket 和团队协作。

什么是 Caesar？

Caesar 是适用于 Windows、macOS 和 Linux 的桌面 API 客户端。你可以构建、发送和测试 HTTP 请求、GraphQL 和 WebSocket，把它们整理成集合并与团队共享，而这一切都在一个简洁的界面中完成，色彩和键盘帮你省下大量点击。

  • 本地优先：在访客模式下，你的集合保存在你的设备上。可离线使用，无需账号。
  • 真正快速：基于 Rust 和 Tauri 构建，而不是打包一个浏览器。
  • 轻松上手：如果你来自 Postman 或 Insomnia，可以导入你的集合，你的 pm.* 脚本照常可用。
  • Fair Source（FSL）：代码公开，可免费使用。它不是开源软件：禁止出售。

适合谁用？适合每天测试 API 的人（后端、前端、QA、移动端），想要一款轻量、私密、无摩擦的工具。也适合需要与团队共享集合、又不想搭建基础设施的人。

为什么这么快

Caesar 的速度并非靠取巧：它源于自身的构建方式。

用 Rust，而不是打包的浏览器请求由 Rust 内核执行，窗口使用系统自带的 Web 引擎。结果是：瞬间启动，内存占用低。
你的数据就在身边集合、变量和标签页都直接从你的磁盘读取，无需等待任何服务器。打开 Caesar 不依赖你的网络连接。
启动时无需加载任何东西没有强制登录界面，没有遥测，后台也没有任何数据分析在运行。
更少点击，更多键盘每个命令都有快捷键，并且可以修改。粘贴一个 cURL，请求就已经构建好了。

安装 Caesar

从下载页面或你的应用商店下载适合你系统的安装程序：

系统文件 / 商店
Windows64 位 .exe 安装程序（也提供 .msi）· Microsoft Store 版本即将推出
macOS（Intel 和 Apple Silicon）通用版 .dmg，已通过 Apple 签名和公证
Ubuntu（Snap Store）sudo snap install caesar，或通过 Ubuntu App Center（Snap Store）安装
Linux.deb（Debian/Ubuntu）或 AppImage（任意发行版）

首次运行时，可能会出现系统警告，尤其是在 Windows（SmartScreen）上。这对新项目来说很正常，警告指南会说明该点击什么。之后，Caesar 会自动更新。

无需命令行。Caesar 是桌面应用：使用它不需要 Node、Docker 或任何额外安装。

你的第一个请求

打开 Caesar，点击新建标签页（Ctrl+T）。选择方法（GET、POST、PUT、PATCH、DELETE、HEAD 或 OPTIONS），输入 URL，然后点击发送或按 Ctrl+Enter。

  1. 在顶部栏中输入 URL。
  2. 点击发送。你会看到请求各步骤的动画（解析域名、建立连接、发送、接收）。
  3. 在下方查看响应：状态、耗时、大小和正文。
  4. 按 Ctrl+S 将其保存到集合。

除了这七种常用方法，你还可以在设置中添加额外方法（例如 WebDAV 的方法）。只有 CONNECT 和 TRACE 会被拒绝。

参数和请求头

Params 和 Headers 标签页使用键值编辑器：你可以添加行，通过复选框启用或禁用而无需删除，URL 会自动更新。

  • 取消勾选某一行，即可在没有它的情况下测试，而且不会丢失它。
  • 你可以在键和值中使用 {{variables}}（参见变量和配置档案）。
  • 如果你粘贴带有 ?a=1&b=2 的 URL，参数会出现在对应的表格中。

请求体

在 Body 标签页中，选择你的 API 所需的格式：

类型使用场景
JSON现代 REST API。带语法检查和语法高亮的编辑器。
文本XML、纯文本或其他原始内容。
Form-data带文件附件的表单（每个文件最大 100 MB）。
x-www-form-urlencoded经典表单。
GraphQL专用的 Query 和 Variables 编辑器（参见 GraphQL）。

出于安全考虑，Caesar 只会附加你在系统文件选择器中选定的文件。

查看响应

响应会显示状态（以颜色区分）、耗时和大小，并提供三种视图：

  • Pretty：格式化、带颜色的 JSON。你可以隐藏空值以便阅读。
  • Raw：原样显示收到的文本。
  • Timeline：各请求步骤及其耗时。

使用 JSONPath 过滤器，只保留你关心的部分，例如 $.data[0].id。使用 Ctrl+F 可在响应中搜索（参见标签页和搜索）。

响应最多读取 10 MB；如果更大，Caesar 会截断并提示你，以免窗口卡死。

粘贴和复制 cURL

如果有人给你一条 curl 命令（来自 API 文档、浏览器开发者工具或同事），直接粘贴到 URL 栏即可。Caesar 会创建包含方法、请求头和请求体的请求。

反过来也一样：将任意请求复制为 cURL，贴到工单里分享，或在终端中运行。为此有专门的命令（没有默认快捷键，你可以自行指定）。

认证

在 Authorization 标签页中选择身份验证方式。Caesar 支持以下类型：

无认证继承BearerBasicAPI KeyDigestNTLMOAuth 1.0OAuth 2.0WSSEAWS Signature v4Akamai EdgeGrid

继承选项最方便：在集合或文件夹上定义一次认证，里面的每个请求都会使用它。令牌变了，只需在一处修改。

提示：把令牌存放在变量（{{token}}）中，并在认证里使用该变量；这样就不必把它粘贴到每个请求里。

变量与配置档案

变量让你可以写 {{baseUrl}}，而不是固定的 URL。共有三个层级：

  • 全局变量：对你所有的集合有效。
  • 集合变量：仅对该集合或文件夹有效。
  • 变量配置档案：命名的变量集（Development、Staging、Production……），通过发送旁边的选择器激活。相当于 Postman 的 Environments。
  • {{x}} 变量在 URL、请求头、参数和认证中会以不同的颜色显示，不会有任何遗漏。
  • 按住 Ctrl 点击变量，可查看并编辑它的值，无需离开当前请求。
  • Ctrl+Space 打开变量选择器。
  • 你可以将变量标记为机密，使其不会一眼就被看到。
  • 从 Postman 导入时，它的 environments 会变成配置档案，它的 globals 会变成全局变量。

测试与脚本

Scripts 标签页会在响应到达时运行脚本（结果显示在响应面板的一个标签页中）。它使用 Postman 风格的语法（pm.*），所以你已有的知识可以直接沿用：

pm.test("responds 200", () => {
  pm.expect(pm.response.code).to.equal(200);
});

const data = pm.response.json();
pm.test("returns users", () => {
  pm.expect(data.length).to.be.above(0);
});
  • pm.test 和 pm.expect 用于检查状态、请求头和正文。
  • pm.response.json() 用于读取已解析的正文。
  • pm.environment.set、pm.collectionVariables.set 和 pm.globals.set 用于存储值。

天生安全。脚本在专用解释器中运行，仅支持 JavaScript 的一个子集：无网络、无文件系统访问，也没有 eval。因此导入的脚本无法在自身作用域之外做任何事。

串联请求

典型场景：登录后，在其他请求中使用令牌。在登录请求中加入一个测试：

const r = pm.response.json();
pm.environment.set("token", r.access_token);

此后，任何请求都可以在请求头或 Bearer 认证中使用 {{token}}。你只需运行一次登录，其余请求就都已认证，无需复制粘贴。

集合和文件夹

集合就是存放请求的笔记本。在侧边栏中创建集合，在文件夹里嵌套文件夹，并通过拖放调整顺序。

  • 每个集合或文件夹都可以拥有自己的变量和授权，其中包含的内容都会继承它们。
  • 自动保存：Caesar 会自动保存，并在你关闭时保留你的标签页和草稿。
  • 你可以与团队共享集合（参见同步和团队）。

代码生成器

通过 </> 按钮，可将当前请求转换为可直接粘贴到项目中的代码。支持 20 种语言和库，包括 cURL、Python（Requests）、JavaScript（Fetch、XHR）、Node.js（Axios）、Go、Rust、Java、Kotlin、C#、PHP、Ruby、PowerShell、Swift 和 Dart。

你可以调整缩进、超时或是否跟随重定向等选项，并一键复制结果。

GraphQL

选择 GraphQL 请求体，Caesar 会提供一个 Query 编辑器和一个 Variables 编辑器，与 Postman 一样：

  • 通过内省加载 schema。
  • 输入时对字段和类型自动补全。
  • Schema 浏览器，用于浏览类型和字段。
  • 美化，一键格式化查询。
  • 根据查询生成变量，存在多个操作时提供操作选择器。

GraphQL 请求可随 Postman 一起导入和导出。

WebSocket

创建 WebSocket 请求，连接后在时间线中查看对话：你发送的和收到的内容，并带有时间和大小。

  • URL 以 ws:// 或 wss:// 开头（如果你使用 http(s)，会自动转换）。
  • 你可以设置子协议，以逗号分隔。
  • 发送文本或二进制消息（十六进制或 base64），并以十六进制转储查看二进制内容。
  • URL 中支持 {{variables}}。

标签页和搜索

想开多少标签页都行。Caesar 会记住你打开过的标签页，并在下次启动时原样恢复。

  • Ctrl+T 新建，Ctrl+W 关闭，Ctrl+1…9 跳转到第 N 个标签页。
  • Alt+← / → 返回之前或之后访问过的标签页。
  • Ctrl+F 在响应或编辑器中搜索。
  • 右键点击或按 Ctrl+Shift+W 可全部关闭，并回到带小猫的主屏幕。

在 macOS 上，Ctrl 换成 Cmd。

工作区

工作区是一组独立的集合、变量和标签页：一个用于工作，一个用于个人项目，每位客户再各一个。你可以通过侧边栏的选择器切换。

访客模式和未开通 Pro 的账号包含一个工作区；开通 Pro 后可以拥有任意多个。

主题、字体和语言

Caesar 内置六款主题：Monokai（默认）、Dracula、Tokyo Night、Nord、One Dark，以及适合偏爱浅色背景用户的 GitHub Light。

你还可以选择字体和文字大小、关闭动画，并调整侧边栏宽度。界面提供西班牙语、英语、德语、法语和意大利语。

同步和团队

开通 Pro 账号后，你可以在多台电脑上使用同一批集合，并与他人共享。

  • 个人同步：你的集合、变量和配置档案会出现在你所有的设备上。更改按条目合并，因此两台设备不会互相覆盖对方的工作。
  • 在你的设备上加密：上传的内容从你的电脑就已加密；服务端只存储无法读取的数据。
  • 恢复密钥：由你自己保管，丢失设备时可用它找回数据。
  • 关联新设备：通过你的另一台设备批准，在两个屏幕上比对一个六位数字验证码即可。
  • 团队：用一个代码共享集合或工作区；输入代码的人即可加入并看到更改。

重要：在共享集合中，任何拥有代码的人都可以读取和修改其内容；没有角色之分。请只把代码分享给应当拥有编辑权限的人。

隐私和安全

  • 无遥测，无数据分析。Caesar 不会发送使用数据。
  • 界面本身不发起任何网络请求：请求由 Rust 内核执行，它会校验 URL、只允许 http 和 https，并限制响应和文件的大小。
  • 你的密钥永不离开系统：加密密钥保存在你操作系统的钥匙串中。
  • 应用采用最小权限和严格的安全策略。
  • 在访客模式下，你的数据永远不会离开你的设备。

更多内容请见安全与隐私以及隐私政策。

更新

Caesar 会自动更新：启动时检查是否有新版本，如有则下载、安装并重启。你的标签页和草稿会被保留。每个安装包都经过签名，应用会在安装前验证签名。

  • 在设置 → 更新中，你可以关闭自动更新，或点击检查更新。
  • 在 Linux 上，如果你通过 Snap Store（sudo snap install caesar 或 Ubuntu App Center）安装 Caesar，Snap 会自动更新；使用 AppImage 时可在应用内更新；.deb 则需手动重新安装。

最佳实践

  1. 对会变化的内容使用变量（服务器、版本、令牌），并为每个环境使用配置档案。
  2. 在集合上定义认证，并让请求保持“继承”。
  3. 为每个重要请求至少添加一个测试：检查状态和正文。
  4. 用“动词 + 资源”命名请求（“List users”“Create order”），并用文件夹分组。
  5. 不时导出一份副本，备份你重要的集合。
  6. 不要把机密留在 URL 中：请使用机密变量或认证。
  7. 每个项目或客户使用一个工作区，避免变量混淆。

故障排查

请求无法连接

检查 URL 是否以 http:// 或 https:// 开头、是否存在未解析的变量（会以不同颜色显示），以及你是否已联网。查看响应时间线：它会告诉你哪一步失败了。

SSL 证书错误

如果你在测试使用自签名证书的本地服务器，请在设置中关闭验证 SSL。访问真实 API 时再重新开启。

我收到 401 或 403

检查 Authorization 标签页：如果设为“继承”，请检查集合上的设置。确认令牌未过期，并且该变量存在于当前激活的配置档案中。

请求超时

在设置中调高超时时间。设为 0 时使用最大值（1 小时），仅用于调试。

我的测试没有任何反应

测试在收到响应之后才会运行，所以你需要先发送请求。如果脚本中有错误，会显示在结果旁边。

我无法同步或共享

这些功能需要 Pro。在访客模式下或账号试用期内，Caesar 仅在本地工作。如果你已经付款，请在账户和订阅中点击我已付款，请检查。

常见问题

Caesar 适合测试 API 吗？

适合：它涵盖 REST、GraphQL 和 WebSocket，支持测试、变量、配置档案、Postman 导入和代码生成，是一款可离线运行的轻量应用。

它免费且开源吗？

访客模式免费，代码也是公开的，但它不是开源软件：它采用 FSL 许可，禁止出售。每个版本在两年后转为 MIT。

我的集合存储在哪里？

在你的设备上。只有当你开启同步或与团队共享时，它们才会离开设备，而且那时会经过加密。

我可以导入我的 Postman 集合吗？

可以。在侧边栏中导入集合文件（以及会变成配置档案的 environments）。

我的 Postman 脚本能用吗？

使用 pm.test、pm.expect、pm.response.json() 的测试以及存储变量的函数都可以。Caesar 使用的是仅支持 JavaScript 子集的安全解释器，因此依赖外部库或网络的脚本无法运行。

有命令行或 CI 集成吗？

目前 Caesar 是桌面应用。你可以把请求导出为 cURL 或代码，用在你的脚本中。

我需要账号吗？

不需要。只有同步和团队协作才需要账号。

它支持哪些系统？

Windows（.exe 和 .msi；Microsoft Store 版本即将推出）、macOS（Intel 和 Apple Silicon）以及 Linux（Ubuntu App Center / Snap Store：sudo snap install caesar，另有 .deb 和 AppImage）。
