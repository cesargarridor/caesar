系统要求

  • Windows：64 位。Caesar 使用系统的 WebView2；如果缺失，安装程序会自动处理。Microsoft Store 版本即将推出。
  • macOS：Intel 或 Apple Silicon（.dmg 为通用版）。
  • Linux：x86_64。在 Ubuntu（以及支持 snapd 的发行版）上，Snap Store 软件包（sudo snap install caesar）已包含所有必需组件。使用 .deb 或 AppImage 时，需要 WebKitGTK 4.1（例如 Ubuntu 22.04 或更高版本）。
  • 无需账号：访客模式无需账号即可使用。

安装步骤

Windows

  1. 下载 .exe（或 .msi）。
  2. 运行并按照向导操作（如果出现 SmartScreen 界面，点击更多信息 → 仍要运行）。
  3. 从“开始”菜单打开 Caesar。

macOS

  1. 下载 .dmg 并打开。
  2. 将 Caesar 拖到“应用程序”文件夹。
  3. 从“应用程序”或启动台打开。

Ubuntu 和 Linux

Ubuntu 及其他发行版

在 Ubuntu 上，最简单的方式是从 Ubuntu App Center（Snap Store）安装，或运行 sudo snap install caesar：一步安装，并自动更新。使用 .deb 时，如果文件位于你的主目录，apt 可能会输出一条无害的提示；AppImage 则需要可执行权限。

终端 — ubuntu

user@ubuntu:~$ # Or with the .deb package:
user@ubuntu:~$ sudo apt install ./Caesar_x.y.z_amd64.deb

对于 AppImage：运行 chmod +x Caesar_*.AppImage 后再打开。如果你的发行版无法运行它，请安装 libfuse2。

为什么会出现这个？这是正常现象

Caesar 是一个源码可见的新项目：它全新发布，还没有下载历史。

SmartScreen 及类似系统会查看文件的信誉，以及它是否拥有付费的代码签名证书。新发布的程序两者都没有，任何新软件都会触发这个警告。

该警告并不意味着它有危险：它只是说明系统还不认识它。你可以自行核实：所有代码都是公开的，你还可以用 SHA-256 哈希验证文件（见下文）。

如何验证完整性

在每个 Release 页面的 Assets 下，GitHub 会在每个文件旁显示 SHA-256 摘要。请计算你所下载文件的哈希值，并核对是否一致：

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

如果不一致，请不要安装，并重新下载。此检查可以发现损坏或被篡改的下载文件，但不能取代代码签名（见下文）。自动更新同样使用 minisign 签名，应用会在安装前验证签名。

自动更新

  • 默认情况下，应用启动时会检查 github.com/cesargarridor/caesar/releases 是否有新版本；如果有，它会自动下载、安装并重启。你的标签页和草稿会被保留。
  • 每个更新包都使用 minisign 签名，应用会在安装前检查签名。
  • 如需关闭：设置 → 更新。你也可以在那里随时点击检查更新。
  • 在 Linux 上，如果你通过 Snap Store（sudo snap install caesar 或 Ubuntu App Center）安装 Caesar，Snap 会在后台自动更新；使用 AppImage 时，可在应用内更新；.deb 则需要手动重新安装。
  • 检查更新时，GitHub 会收到你的 IP 地址和一个标准请求；详情请参阅隐私政策。
