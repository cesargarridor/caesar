Voraussetzungen

  • Windows: 64-Bit. Caesar nutzt das System-WebView2; der Installer kümmert sich darum, falls es fehlt. Bald im Microsoft Store.
  • macOS: Intel oder Apple Silicon (die .dmg ist universell).
  • Linux: x86_64. Unter Ubuntu (und Distributionen mit snapd) enthält das Snap-Store-Paket (sudo snap install caesar) alles Nötige. Mit .deb oder AppImage wird WebKitGTK 4.1 benötigt (zum Beispiel Ubuntu 22.04 oder neuer).
  • Kein Konto nötig: Der Gastmodus funktioniert ohne.

Installationsschritte

Windows

  1. Lade die .exe (oder die .msi) herunter.
  2. Führe sie aus und folge dem Assistenten (erscheint der SmartScreen-Bildschirm, klicke auf Weitere Informationen → Trotzdem ausführen).
  3. Öffne Caesar über das Startmenü.

Bald im Microsoft Store: Bis dahin erscheint beim direkten Installer weiterhin der SmartScreen-Bildschirm, doch sobald die App im Microsoft Store veröffentlicht ist, kannst du sie dort herunterladen und diese Warnung erscheint nicht mehr.

macOS

  1. Lade die .dmg herunter und öffne sie.
  2. Ziehe Caesar in den Ordner „Programme“.
  3. Öffne es über „Programme“ oder das Launchpad.

Ubuntu und Linux

Unter Ubuntu kannst du es über das Ubuntu App Center (Snap Store) installieren oder indem du im Terminal Folgendes ausführst:

sudo snap install caesar

Wenn du das .deb-Paket bevorzugst (Ubuntu/Debian):

sudo apt install ./Caesar_x.y.z_amd64.deb

oder mit dem AppImage auf jeder Distribution:

chmod +x Caesar_x.y.z_amd64.AppImage
./Caesar_x.y.z_amd64.AppImage

Ubuntu und andere Distributionen

Unter Ubuntu ist die einfachste Option die Installation über das Ubuntu App Center (Snap Store) oder mit sudo snap install caesar: Sie erfolgt in einem Schritt und aktualisiert sich automatisch. Beim .deb kann apt einen harmlosen Hinweis ausgeben, wenn die Datei in deinem Home-Ordner liegt; das AppImage braucht Ausführungsrechte.

Terminal — ubuntu
user@ubuntu:~$ sudo snap install caesar
caesar 0.18.25 from Cesar Garrido installed
user@ubuntu:~$ # Or with the .deb package:
user@ubuntu:~$ sudo apt install ./Caesar_x.y.z_amd64.deb
Reading package lists... Done
...
N: Download is performed unsandboxed as root as file '/home/user/Caesar_x.y.z_amd64.deb' couldn't be accessed by user '_apt'. - pkgAcquire::Run (13: Permission denied)

Für das AppImage: chmod +x Caesar_*.AppImage und anschließend öffnen. Falls deine Distribution es nicht startet, installiere libfuse2.

Warum erscheint das? Das ist normal

Caesar ist ein neues Projekt mit einsehbarem Quellcode: Es ist ganz neu und hat noch keine Download-Historie.

SmartScreen und ähnliche Systeme prüfen die Reputation einer Datei und ob sie ein kostenpflichtiges Codesignatur-Zertifikat hat. Ein frisch veröffentlichtes Programm hat beides nicht, und die Warnung erscheint bei jeder neuen Software.

Die Warnung bedeutet nicht, dass es gefährlich ist: Sie bedeutet, dass das System es noch nicht kennt. Du kannst es selbst prüfen: Der gesamte Code ist öffentlich und du kannst die Datei anhand ihres SHA-256-Hashs (unten) verifizieren.

So prüfst du die Integrität

Auf jeder Release-Seite zeigt GitHub neben jeder Datei unter Assets einen SHA-256-Digest an. Berechne den Hash der heruntergeladenen Datei und prüfe, ob er übereinstimmt:

# Windows (PowerShell)
Get-FileHash .\Caesar_x.y.z_x64-setup.exe -Algorithm SHA256
# macOS
shasum -a 256 Caesar_x.y.z_universal.dmg
# Linux
sha256sum Caesar_x.y.z_amd64.AppImage

Stimmt er nicht überein, installiere sie nicht und lade sie erneut herunter. Diese Prüfung erkennt beschädigte oder manipulierte Downloads, ersetzt aber keine Codesignatur (siehe unten). Automatische Updates sind außerdem mit minisign signiert, und die App prüft die Signatur vor der Installation.

Automatische Updates

  • Standardmäßig prüft die App beim Start auf github.com/cesargarridor/caesar/releases, ob es eine neue Version gibt; falls ja, lädt sie diese herunter, installiert sie und startet selbstständig neu. Deine Tabs und Entwürfe bleiben erhalten.
  • Jedes Update-Paket ist mit minisign signiert, und die App prüft die Signatur vor der Installation.
  • Zum Ausschalten: Einstellungen → Updates. Dort kannst du auch jederzeit auf Nach Updates suchen klicken.
  • Wenn du Caesar unter Linux aus dem Snap Store installierst (sudo snap install caesar oder das Ubuntu App Center), aktualisiert Snap es automatisch im Hintergrund; beim AppImage aktualisiert es sich in der App, und das .deb muss von Hand neu installiert werden.
  • Bei der Update-Prüfung erhält GitHub deine IP-Adresse und eine Standardanfrage; Einzelheiten findest du in der Datenschutzerklärung.

Datenschutz

Caesar enthält weder Telemetrie noch Analytics. Im Gast-/lokalen Modus verlassen deine Daten nicht dein Gerät; bei Sync werden nur verschlüsselte Blöcke hochgeladen. Pro ist ein Abonnement, das sich automatisch verlängert: Preis und Abrechnungszeitraum werden vor der Zahlung angezeigt, du kannst jederzeit kündigen und erhältst eine 14-tägige Rückerstattung (Rückerstattungen, Bedingungen).
